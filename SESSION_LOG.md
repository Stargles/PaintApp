No code changed and **no test run was taken, deliberately**: the branch is three markdown files and three other agents held `simlock.sh`'s slots. **The headline is that this is much smaller than it looks, and the citations are the deliverable.** Every hard part is already shipped for the vector eraser: `StrokeGeometry.splitRuns(_:inside:)` is *literally* a selection clip — its own doc says so, and `StrokeCanvasView` already uses it to stop a stroke drawn across a selection from bridging the gap — `VectorCanvas.cutAlongFootprint`/`cutToIntersection` are the splice template, `DabLattice` + `stampStroke(visibleRange:)` keep a cut piece's dabs bit-identical, and `registerVectorFillUndo` is the whole-array undo shape. **The gap is one branch**: `TopToolbar.toggleMove()` checks `activeLayerIsVector` before it looks at anything and never reads `canvasManager.selection`, so the lasso stays on screen while `setVectorTransform` moves the entire cel — exactly the report. **The two questions the brief called hardest both came back the other way.** *Fills are the easy half*: `VectorFillElement` is an archived `CGPath`, so a chunk is `CGPath.intersection`/`.subtracting` — Core Graphics, iOS 16+, against a 26.5 deployment target — and a standalone `swiftc -O` harness MEASURED that the results are **fill-rule normalised** (a split donut's halves render identically under winding and even-odd), that **area is conserved exactly** (2200 + 6200 = 8400), that a grazing loop returns `isEmpty` and a containing loop empties the other side (two free fast paths), and that the cost is **0.86 + 1.27 ms** for an 8000-point fill against a 1500-point loop. *Strokes are the fiddly half*, and the load-bearing find is the **dab lattice**: `VectorCanvas.stamp` renders a piece from `lattice?.samples ?? stroke.samples`, so translating a piece's samples and leaving its lattice alone draws it **where it used to be** — and the eraser's `piece.lattice = nil` is equally wrong here, because re-anchoring re-phases every dab, so the half the artist did *not* touch would visibly change. The rule is asymmetric: **the stationary piece keeps the parent's lattice verbatim; the moved piece keeps it with `lattice.samples` translated by the same delta**, `parameters` and `seedID` untouched — which makes a translation bit-exact and is one of the reasons stage 1 is translation-only. **Recommended centreline over ink**, on four grounds, the deciding one being that `cutToIntersection`'s own comment already states the same assumption and the owner accepted it; ink membership is a *signed distance to the polygon*, which `CGPath` does not expose at all, so it is a day's work behind a setting rather than a constant change. **`conservativeCuts` must NOT be reused** — its half-width inset exists to hide a cut under a retained punch, and a move has no punch, so insetting would open a visible gap on both sides. **Text moves whole iff its bounding-box centre is inside** — the stroke rule rounded to the nearest whole object; *intersects* drags a paragraph out of the page and *wholly contains* silently leaves a title behind. **Erase punches move like the strokes they are**, because a hole that stays put while its ink leaves *heals* and then `collectResidueGarbage()` deletes the orphan, making the healing permanent. **Undo is a session, not `b100d65`'s bracket** — that bracket stores two affines and its own doc says that suffices *because a transform touches nothing else in the cel*, which a display-list rewrite does; what is inherited is its lesson, close-however-it-ends, which `beginCanvasEdit()` already delivers for free. **One artefact named rather than tuned away**: `BrushStamper`'s boundary dab is inclusive, and a *move* split is the first case whose two ranges abut, so one dab is double-stamped at zero delta — invisible above opacity 1, pinned by a test. **Interpolation is out of scope and safe**: an in-between is already refused by `toggleMove`'s existing guard, and a split on a keyframe only demotes tier 0 to the point-cloud path, which the eraser already does. Staged strokes → fills → whole objects → follow-ups, each with named headless tests asserting identities. **A separate, reachable defect found while scoping and left alone**: `SelectPanel`'s Duplicate calls `beginDuplicate()` directly, which has no vector branch and rasterizes a lassoed region onto a new raster layer. **What needs the owner**: whether the centreline rule feels right on their actual line weights, and whether the loop should survive a move.
